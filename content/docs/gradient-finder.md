# How To Use
This tool is reltively straight forward but we'll give you some tips on how to use it! If you don't know how it will look, you can always use our gradient preview!

**1. The Search Bar**
- We offer a search bar which lets you input any hex code to quickly find a gradient that's close to it! The gradients are all premade so we can't promise every possible one but it can act as a great start! This is a great option if your roles already have one color!

**2. Gradient Selector**
- As kind of mentioned before, we have a gradient selector! This give you a small collection of premade gradients that you can copy directly or use as a baseline to get closer to what you want!

**3. Gradient Customizer**
- Once you have a baseline or a gradient close to what you want, you can use our gradient customizer to get it exactly how you want! You can either paste in differnt hex codes or you can click (or tap) the color box to open a simple color selection tool!
