# How To Use
Like many of the other tools, this one is pretty straightforward! Simply take a userID or snowflake and paste it into the tool! The tool will then respond with the related data. If you are unsure of how to get IDs, this guide should help you out:

### Getting a UserID
**1. Enable Developer Options**
- Go to your settings and scroll all the way down! There you can find an option to enable developer settings

**2. Get the ID**
- For Desktop: Right click the user's profile, click to copy ID
- For Mobile: Open a user's profile, tap the 3 dots at the top, and tap to copy the ID

### Getting a Snowflake
**1. Enable Developer Options**
- Go to your settings and scroll all the way down! There you can find an option to enable developer settings

**2. Get the ID**
- For Desktop: Right click just about anything and it should give you an option to copy it's ID!
- For Mobile: Tap and hold just about anything and it should give you an option to copy it's ID!

***Pro Tip: A snowflake is just an ID for other things on Discord! You can get a snowflake (ID) from things like channels, tags, roles, and more!***
