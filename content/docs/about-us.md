# About Us
This site is run by myself (Soul) along with the awesome help from community contributors. The point of this project is to quite literally provide every single possible tool that a website can provide right in one place that is both easy to use as well as feature rich. These tools are constantly being improved and the list simply grows longer! 

A full list of contributors can be found on the "contributors" page! if you are interested in helping out or learning more, feel free to join our discord server! There you can connect directly with us as well as other people using the site!

## How Do We Make Money?
Short answer, we don't! This site is run entirely out of pocket as our goal is to provide useful tools for free rather than paywalling them. We do not collect personal information and we do not serve ads that way we can make your visits both private as well as simple!

## How Can I Join The Team?
We do not have team applications like most server so here's a short explanation! I and the other active team members watch for people doing a great job in the community. This could be helping make the site better, contributing to resources, or helping answer questions! When we see someone we find promising and trustworthy, we will reach out with an invite! We find this is a bit better of an system that way we can ensure that anyone joining the team is actually passionate towards the project :)
