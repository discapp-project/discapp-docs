# How To Use
To use this tool, simply paste either the emoji CDN link or the emoji tag into the input! If you aren't sure how to get this information, this guide might help:

**1. For Desktop**
- Send the emoji in any text channel.
Add a backslash `\` right before the emoji and press Enter.
Copy the resulting formatted text (e.g., `<:pepe:123456...>`).
Paste it into the input box above.

**2. For Mobile**
- Send the emoji in a channel or DM.
Tap and hold the sent message, then tap Copy Text.
Paste the copied raw tag directly into the input above.
Alternatively, long press the emoji image directly and tap Copy Image Link.

***Pro Tip: If you have vencord, you can use the "CopyEmojiMarkdown" plugin to quickly copy the emoji tag and ID to paste above! Alternitively, you can skip this tool enitrely using the "ExpressionCloner" plugin***
