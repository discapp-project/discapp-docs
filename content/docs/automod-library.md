## What is it?
This is a community made library containing regexes for your server's automod! These are separated by types and usecases so you can use our search options to find any ones that you specificaly want!

## How to Contribute
If you have any regexes that you would like to contribute, you can let us know by joining our community discord server! There, you can make a post in our suggestion channel and put the regexes you have! When our team sees it, they can add it to the site! Alternitively, you can make a pull request on the official discapp-web github repo with your page added!

If you do decide to contribute, please make sure that the regexes you want to contribute haven't already been added!
