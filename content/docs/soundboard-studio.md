# How To Use
This tool allows you to upload audio clips and turn them into soundboard options (we'll refer to them as sounds) that Discord supports! To use, simply find the clip you want to make into a sound and upload it to the tool by either clicking the button or dragging the file into the editor. If the audio file is not something we support, consider converting it using other online tools!

Once you've uploaded it, you can change the timing and other factors of the clip before downloading! When you download it, you can than go to your server settings -> soundboards -> and upload it there.
