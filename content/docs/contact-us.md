# Contact Us
Below is a list of ways you can get in touch! Some ways are faster than others so we'll list them from fastest to slowest!

**1. Discord Community**
- This is the fastest way to get help! Here you can not only reach out to the team but you can also get help from other community memberes who are also passionate about the project!

**2. Through Email**
- You can contact us through email though this one heavily depends on the context of the issue. The two emails that are available are `support@discapp.org` for support questions or `legal@discapp.org` for legal questions and concerns!

**3. Github Issues**
- This one is less for support and more for contributing to improve Discapp however if you do have any questions or concerns, github issues can be used! The downside is that it normally takes a bit longer to reply to them!

**4. Direct Messages**
- We prefer if you don't message us via direct messages however if you are unable to get a response through any other channel, this is still an option. Keep in mind that we don't generally respond to DMs so we cannot promise you can get assistance via that method.
