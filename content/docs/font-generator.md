# How To Use
Though this tool is mostly for usernames, you can put in any type of text you want to apply the effects! Once you paste the text you want, you can scroll through the available fonts and when you have found the one you want, simply click or tap "copy"! This will save it to your clipboard so it can be pasted wherever you would like to use it! Keep in mind that some fields (like channel names) don't allow fonts while other fields like usernames do!
