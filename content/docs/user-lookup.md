# How To Use
Using this tool is really simple! Just input the user ID of the person you want to get info on, solve the captcha, and click the lookup button! If you aren't sure how to get the user ID here is a step by step guide:

**1. Enable Developer Options**
- Go to your settings and scroll all the way down! There you can find an option to enable developer settings

**2. Get the ID**
- For Desktop: Right click the user's profile, click to copy ID
- For Mobile: Open a user's profile, tap the 3 dots at the top, and tap to copy the ID

# How Does It Work
This tool works by sending a request to Discord's API to get information on a user! We are able to get more information that other sites because we do not use discord's public API! Rather, we use their bot api which provides a lil bit more info. That is also the reason we serve captchas as to use this bot API, we have to make calls *with* a bot token
