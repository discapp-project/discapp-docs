# How To Use
This tool allows you to easy resize lots of differnt assets! Note, this does not include emoji or sticker resizing as that feature is built into the asset stealer tool. To begin, use the sidebar and click the type of asset you would like to modify. Once you have, simply upload it and the tool will open the editor! There you can resize it to however you like along with a preview of what it *should* look like!
