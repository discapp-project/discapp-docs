# How To Use
Just like the user lookup, this tool is very simple to use! Simply paste a server ID *or* a server's invite link to get information about the server! If you are unsure of how to get ID, you can follow the guide below: 

**1. Enable Developer Options**
- Go to your settings and scroll all the way down! There you can find an option to enable developer settings.

**2. Get the ID**
- For Desktop: Right click the server icon, click to copy ID
- For Mobile: Tap and hold a server's icon, tap "more options", scroll down, and tap to copy ID
